03 / HANDOFF

交付不是丟一個網址。

每個專案都應用同一個移交流程，讓「完成」有可驗收的定義。

  1. 01

    帳號與所有權

    網域、託管、CMS、分析與金流帳號列冊；客戶是 owner，Clancy 是 collaborator。

  2. 02

    內容與功能驗收

    以 scope checklist 驗收頁面、裝置、表單、連結、SEO、效能與無障礙；書面 sign-off。

  3. 03

    操作教學

    $2k 以上提供錄影與 60 分鐘教學；只教客戶會改的內容，不暴露容易破壞版面的權限。

  4. 04

    保固與維護

    定義 bug 保固期、回應時間與「新需求」界線；期滿轉單次更新或月維護。

  5. 05

    封存與退出

    交付 repo、設計檔、內容匯出、密碼管理清單與復原方式；確認最後一筆款項。
